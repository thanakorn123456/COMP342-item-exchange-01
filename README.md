# COMP342 — ระบบแลกเปลี่ยน/ส่งต่อสิ่งของภายในมหาวิทยาลัย

## Lab 4: Implementation + Git

โครงงานเป็นระบบแลกเปลี่ยน/ส่งต่อสิ่งของที่ยังใช้งานได้ภายในมหาวิทยาลัย

## สมาชิกและหน้าที่

| สมาชิก | หน้าที่ |
|---|---|
| น.ส.กมลวรรณ แก้วเจิม (สนุ๊กเกอร์) | รวบรวมข้อมูล สรุปปัญหา เขียนสรุปรายงานภาพรวม และดูแลเอกสาร README |
| นายธนากร บานเย็น (ต้น) | วางโครงสร้างทางเทคนิค ภาษาที่ใช้ และฐานข้อมูลที่ใช้พัฒนา รวมถึงดูแลโครงสร้าง Repository |
| นายศิลาชัย บูรณะสิน (ม่อน) | จัดทำแผนและทำหน้าที่ทดสอบระบบ รวมถึงดูแลโฟลเดอร์ tests |
| นายณัฐภัทร หอมละออ (มิน) | เขียนแผนผังขั้นตอนการทำงานและจัดทำผังความสัมพันธ์ข้อมูล รวมถึงช่วยออกแบบโครงสร้างโมดูล |
