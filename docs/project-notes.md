# Project Notes

## Team Responsibilities

- น.ส.กมลวรรณ แก้วเจิม (สนุ๊กเกอร์): รวบรวมข้อมูล สรุปปัญหา เขียนสรุปรายงานภาพรวม
- นายธนากร บานเย็น (ต้น): วางโครงสร้างทางเทคนิค ภาษาที่ใช้ และฐานข้อมูลที่ใช้พัฒนา
- นายศิลาชัย บูรณะสิน (ม่อน): จัดทำแผนและทำหน้าที่ทดสอบระบบ
- นายณัฐภัทร หอมละออ (มิน): เขียนแผนผังขั้นตอนการทำงานและจัดทำผังความสัมพันธ์ข้อมูล
